# LaslesVPN: английская и русская версии сайта (EN + RU)

Дата: 2026-10-01 · Статус: на согласовании

## Цель

Сделать сайт полностью двуязычным: английский по адресам `/…`, русский по адресам `/ru/…`.
Переводится всё, что видит посетитель: интерфейс, личный кабинет, блог, FAQ, Privacy/Terms,
инструкции по платформам, названия стран и городов.

**Готово, когда:**
- у каждой страницы есть русская версия по тому же пути с префиксом `/ru`;
- переключатель EN/RU в шапке ведёт на ту же страницу на другом языке, query и hash сохраняются;
- сборка падает, если в русском словаре нет ключа; тесты падают, если в русском контенте нет
  статьи, вопроса, раздела, платформы, страны или города;
- `npm run i18n:scan` не находит в `.tsx` непереведённых пользовательских строк;
- полный ручной проход по `/ru/…` (вход → оплата → кабинет, блог, серверы, страницы из футера)
  не показывает английского текста, кроме намеренных исключений (см. ниже).

**Не входит в задачу:** SSR и пререндер, переводные slug'и в URL, смена валюты, другие языки.
Архитектура не должна мешать добавить третий язык, но специально под это ничего не делается.

## Подход

Своя небольшая i18n-система без зависимостей (вариант A из обсуждения). Альтернативы
`react-i18next` (лишние зависимости, строковые ключи без проверки типов) и «язык только в
localStorage без URL» (русской страницей нельзя поделиться по ссылке) отклонены.

## 1. Ядро и маршруты

### Модуль `src/i18n/`

| Файл | Назначение |
|---|---|
| `locales.ts` | `type Locale = 'en' \| 'ru'`, `defaultLocale = 'en'`, `prefix(locale)` (`''` / `'/ru'`), `localize(path, locale)` добавляет префикс, сохраняя `?query` и `#hash`; `stripLocale(pathname)` → `{ locale, path }`; `switchPath(location, locale)` строит путь для переключателя |
| `en.ts` | словарь интерфейса: вложенный объект по разделам (`header`, `footer`, `auth`, `checkout`, `dashboard.devices` …); значения бывают строками или функциями, например `(n: number) => string` |
| `ru.ts` | `export const ru: Dictionary = {…}`, где `Dictionary` выводится из `en`, а строковые литералы расширены до `string`; если ключа или функции нет, сборка падает |
| `plural.ts` | `plural(locale, n, forms)` на основе `Intl.PluralRules` (`one/few/many/other`) |
| `format.ts` | `formatDate`, `formatMonthYear`, `formatNumber`, `formatPrice` через `Intl` с текущей локалью; заменяют пять жёстко заданных вызовов `'en-US'` и `formatDate` из `blog.ts` |
| `LocaleProvider.tsx` | контекст с `locale` и словарём; язык берётся из props (из маршрута), отдельного состояния нет, поэтому источник правды всегда URL |
| `useT.ts`, `useLocale.ts` | доступ к словарю и локали |
| `LocalLink.tsx` | `LocalLink` / `LocalNavLink` — обёртки над `Link`/`NavLink`, сами добавляют префикс |
| `useLocalNavigate.ts` | `navigate` с префиксом |
| `usePageMeta.ts` | `document.title`, `<meta name="description">`, `<html lang>`, `<link rel="alternate" hreflang>` для en/ru |
| `LanguageSwitcher.tsx` | переключатель EN/RU (в шапке и в мобильном меню) |

### Маршруты

- Список страниц из `App.tsx` выносится в `siteRoutes()` и подключается дважды: под `/` в
  `<LocaleProvider locale="en">` и под `/ru` в `<LocaleProvider locale="ru">`. Список страниц
  остаётся один.
- Пути и slug'и одинаковые в обоих языках: `/ru/blog/public-wifi-risks`, `/ru/countries/germany`.
- Все внутренние ссылки (55 `to="/…"`), 6 вызовов `navigate()`, `RequireAuth`, `useConnectHref`
  и параметры `next=` начинают учитывать префикс. Значение `next` хранится вместе с префиксом:
  после входа пользователь возвращается на ту же языковую версию.
- Неизвестный путь под `/ru/…` показывает русскую 404.

### Запоминание языка

- При переключении язык сохраняется в `localStorage['laslesvpn.locale']` (через try/catch, как в
  `AuthProvider`).
- Если посетитель открывает корень `/` и раньше выбрал `ru`, его один раз перенаправляет на
  `/ru`. Прямые ссылки на страницы (`/blog/x`) никуда не перенаправляют, чтобы английскими
  ссылками можно было делиться.
- Язык браузера (`navigator.language`) не учитывается: адрес решает однозначно.

## 2. Контент из `src/data/`

### Текстовые данные: параллельные файлы одной формы

| Сейчас | Становится | Примечание |
|---|---|---|
| `blog.ts` (8 статей) | `blog.ts` (тип, логика) + `blog.en.ts` + `blog.ru.ts` | `getPosts(locale)`, `getPost(slug, locale)` |
| `faq.ts` (13 вопросов) | `faq.ts` + `faq.en.ts` + `faq.ru.ts` | `getFaq(locale)`; `link.to` хранится без префикса |
| `legal.ts` | `legal.ts` + `legal.en.ts` + `legal.ru.ts` | id разделов совпадают (якоря) |
| `platforms.ts` (5 платформ) | общие поля (`id`, `version`, `size`, `file`, `icon`) в `platforms.ts`; `steps`, `troubleshooting`, `requirements` в `platforms.en.ts` / `.ru.ts` | `getPlatforms(locale)` |

### Структурные данные: перевод только подписей

- **Серверы, страны, города:** структура `servers.ts` не меняется. Русские названия задаются
  таблицей в `servers.ru.ts`: около 30 стран и 53 города. Slug'и стран остаются английскими.
- **Регионы:** вместо `'Asia Pacific'` и других английских строк стабильные id
  (`americas`, `europe`, `apac`, `mea`), подписи берутся из словаря.
- **Категории блога:** id (`all`, `privacy`, `guides`, `product`, `travel`), подписи из словаря.
- **Поиск на /servers** ищет и по английскому, и по русскому названию.
- **Сортировка стран:** `localeCompare(…, locale)`.
- **Тарифы:** `name` и `perks` по `PlanId` из словаря; цены в USD, форматирует `Intl`.

### Намеренно остаётся на английском

Бренд «LaslesVPN», названия ОС и магазинов приложений, имена авторов отзывов, номера версий
и имена файлов. Сами тексты отзывов переводятся.

## 3. Проверка и тесты

- **Vitest** (новая dev-зависимость, `npm test`) только для чистой логики:
  - `localize` / `stripLocale` / `switchPath`: hash, query, корень, `/ru` и `/ru/`, пути, похожие
    на префикс (`/russia` — это не `/ru`);
  - `plural` для 0, 1, 2, 5, 11, 21, 22, 25;
  - `formatDate` / `formatPrice` для обеих локалей;
  - полнота контента: одинаковые множества slug'ов и id в `en` и `ru` (блог, FAQ, legal,
    платформы), у каждой страны и города из `servers` есть русское название, у каждого региона
    и категории есть подпись.
- **Типы:** `npm run build` (`tsc -b`) проверяет полноту словаря.
- **`npm run i18n:scan`:** скрипт ищет в `src/**/*.tsx` текст между тегами и строковые атрибуты
  `placeholder`, `aria-label`, `alt`, `title`, которые не прошли через словарь. Это эвристика для
  контроля, а не барьер сборки; исключения перечислены в самом скрипте.
- **Вручную** на `npm run dev -- --port 5174`: переключатель на каждой странице, вход/регистрация
  с `next`, оплата, четыре вкладки кабинета, фильтры блога и серверов, 404 в обоих языках,
  перезагрузка на `/ru/…`, мобильное меню.
- В конце каждого этапа обязательны `npm run lint`, `npm test`, `npm run build`.

## 4. Этапы

Каждый этап — отдельный коммит, после каждого сайт рабочий.

1. **Ядро:** `src/i18n/`, Vitest, двойное дерево маршрутов, `LocalLink`, `useLocalNavigate`,
   переключатель, запоминание языка, `usePageMeta`. Тексты пока английские.
2. **Ссылки:** механическая замена ссылок, `navigate`, redirect'ов и `next=` на версии с префиксом.
3. **Интерфейс:** шапка, подвал, главная (Hero, Features, Network, Pricing, Testimonials), вход,
   регистрация, 404.
4. **Оплата и личный кабинет:** Checkout, Overview, Devices, Billing, Settings, включая
   множественные формы и даты.
5. **Каталоги:** Servers, Countries, Country, Locations, Download, Tutorials, Tutorial.
6. **Контент:** FAQ, блог (8 статей), About, Help, Affiliate, Partners, What is VPN, Privacy, Terms.
7. **Финал:** `i18n:scan` без находок, ручной проход, обновление README.
